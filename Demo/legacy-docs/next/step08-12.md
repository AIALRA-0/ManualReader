# 在隔离环境怎样打开 STEP-08～12 成品

从本轮输出目录启动。该目录包含 `inputs/`、`media/` 和 `upstream07/`，写作与融合产物由此前已验收的 0.7.1 提供。命令将派生文件写到 `jobs/`，真实请求回执写到 `requests/`，运行统计写到 `metrics/`。

```powershell
$run = '本轮隔离输出目录的绝对路径'
$legacy = '已验证的旧 Reader 源码目录'
$originalProjects = '含原件的 STEP-05/06 隔离项目根目录'
manualreader-finish $run all
manualreader-finish-reader --run $run --legacy $legacy --original-projects $originalProjects --port 9078
```

`all` 会提交就绪的原文翻译与各篇后处理。分开启动时，可以先用 `translate`，再用 `finish` 读取已返回的翻译。翻译使用现有 DS 线路，后处理使用现有 Sol Low 线路。使用原配置提供认证，程序从进程环境读取；本轮证据只保存请求内容、结果及用量。

## 怎样确认成品属于本轮任务

`jobs/<sample>/run.json` 给出阶段回执。打开 `reader-service-ready.json` 中的样本链接，在旧 Reader 页面阅读原文、译文、讲解和附件。`alignment.json` 列出真实来源对应关系，`resource-explanations.json` 区分完整、部分和未取得的解释。保留部分数据时，最终报告列出对应 ID。

`reader-isolated/` 为独立的运行数据目录。预览和模拟提交均在此落地；正式 Reader 的保存需要独立授权。
