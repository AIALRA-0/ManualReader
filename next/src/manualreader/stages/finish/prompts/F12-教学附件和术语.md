# F12 · 章首/章末/阅读路线/六项回顾 + 术语（单章一次合批 Sol Low）

你负责从已完成的 Reader 正文中提取**独立教学附件**，不是重新写 C3、不另起一个教学章。输入给出：当前写作模式、真实章节标题与 Part/Block 的完整内容、当前 STEP-02 读者/教师知识目标（仅作线索）、真正已保存的上一章必要内容和可能已确认的下一章范围、已存术语词典与已有候选。所有 Part/Block、术语 reuse_id 必须来自输入。

**阅读导航**：根据实际 Part 顺序给出简短、具体的阅读路线；导言说明当前真正讨论的主题及与确实存在的前文怎样承接；章末只概括当前已得到的认识和实际已知的后续联系。没有上一章不编回顾；没有已确认的下一章不凭空预告；不能重复正文中已自然接好的 07 过渡或制造“下面将依次……”模板句。ANSWER 模式不硬生造章首、章末，按需要给短导航。

**六项回顾**：对真正适用的 Part，从已写内容分别提炼 `背景 / 问题 / 结论 / 原因 / 依据 / 用法`。每项有信息就短而准确写，没有依据就留空或说明缺证据；不为六格漂亮而添加实验数据、独立问题、结论和个人建议。INTRO 仍然是宏观导读，FINALE 仍然是跨章综合，ANSWER 仍然直答真实子问，不能按 NORMAL 的模板硬套。

**术语候选**：识别当前读者真正需要明白的专业名词、英文缩写、数学符号和关键概念，**不只看已有词表是否非空**，必须找这次正文缺少的关键术语。已有同义同义域定义时返回 `reuse_existing` 加真实 reuse_id；同名不同义不得冒用。新术语给出准确名称、必要别名/中文与英文全称、清楚的 `definition`（是什么及条件）和互补的 `intuition`（在本章有何作用/如何直观理解），既不空洞也不强行凑字数。尽量落到实际 Block/Part；可先不填写无法核实的 source_id，由程序通过已有 S-E Block 关联补齐。禁止把每个普通名词都写成术语，也不要遗漏实际反复使用的关键术语。

本任务的新增文字应自然、具体，逻辑清楚，避免装饰性冒号、防御性套话与无意义的抽象名词并列；**不在此阶段处理中文句号和固定排版格式**，统一交最终格式器。

严格返回 JSON：`guidance:{chapter_intro,reading_flow:[{part_id,title,focus}],part_recaps:[{part_id,background,question,conclusion,causes,evidence,application,status}],chapter_outro,uncertainties:[]}`，`terms:[{action:"reuse_existing|new",reuse_id,name,aliases,definition,intuition,part_ids,block_ids,source_ids,status:"candidate|reused|needs_review"}]`。F12 只是中间请求合同，程序投影为唯一正式 `chapter-guidance-v1` 与 `terms-candidates-v1`，不能把新 JSON 键另存成第二套竞争正文。对模式不适用的附件合法返回空字段/数组；不生成练习或用户问答。

每个适用 Part 在原六项后填 synthesis，写一段自然综合；next_transition 根据真实紧邻 Part 或已确认的下一章承接，范围未知填空。chapter_outro 是读者在全章最后看到的一次回顾，综合本章的关键问题、结论及其依据，有真实的下文才加承接。其余逐 Part 信息用于组织附件。补充术语的 chinese_name、english_name、abbreviation，材料不支持时填空。

新术语沿用 Reader 术语库的两段式要求。定义至少 80 个非空白字符，讲清对象、适用条件和实际机制，第一次用到必要的前置概念时当场解释。直观解释至少 100 个非空白字符，选一个具体过程、可观察的情形或贴切的类比，把对象、动作和结果对应回真实概念。两段都应当能离开原章独立读懂，每句提供新的信息。已有同义术语继续复用。
