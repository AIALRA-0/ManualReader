记录日期为 2026-10-30，使用隔离的合成材料；没有把检查结果写成真实用户的已读进度，没有重写旧文章或笔记

确定性检查覆盖回答头部换行、旧格式兼容、术语大小写、实际图片引用、生成图片上传与路径限制、普通 PDF 文字不自动附上整页图片

浏览器检查覆盖桌面与手机、明暗主题、问题与笔记默认折叠、表格和带文字的流程图、术语四种显示方式、歧义别名跳过、重复渲染、代码与公式保护、提问框不带动其他栏目滚动

浏览器合成麦克风测试走完了录音、上传、离线转写、插入问题框和自动保存；没有用合成测试代替真实手机麦克风验收

# 2 提示词怎样比较

相同八道合成问题分成两组，包含矩阵系数、布局流程、处理宽度、缓存、渗透、请求重试、条件概率与温控；其中四类新材料没有出现在规则例子中

两版均使用 Terra high、普通服务、最多两路并行，保留术语和选择题，没有审稿 Agent 或循环修复

- 旧版两组分别用时 30.669 秒、37.002 秒；输入共 46,630 token，其中缓存 32,000，输出 5,103
- 新版两组分别用时 37.741 秒、41.252 秒；输入共 26,947 token，其中缓存 16,640，输出 5,768
- 按输入、缓存读取、输出分别每百万 1、0.05、5 美元估算，旧版约 0.041745 美元，新版约 0.039979 美元

输入量降低约 42%，估算文本费用降低约 4%；本次回答更长，组内耗时没有降低，不能宣称提速

价格依据为 [OpenAI 的 Terra 官方模型页面](https://developers.openai.com/api/docs/models/gpt-6.1-terra)，这是按 CLI 可见 token 换算的文本 API 等价费用，不是订阅扣费账单；没有把开发对话、发布操作或独立图片生成费用当作零成本，也没有在 CLI 未返回缓存写入分类时猜测它的账单

# 3 实际回答改善在哪里

人工对照发现，新版矩阵回答先说明位置和连线，再从同一个距离例子得到系数；缓存回答区分命中、未命中与淘汰，说明字典和链表各自怎样变化

改进来自同一次写作中的简短教学计划和必要前置约束，没有增加第二个检查模型；但复杂材料仍可能出现抽象跳步，例如渗透材料中的化学势还需要结合读者背景继续解释

这些是少量样本的观察，不能证明任何材料都能一次讲透，也没有给出未经验证的质量百分数

# 4 图片和术语怎样检查

模型读取了一张真实附带的合成信号图，正确区分两条路径，并在回答中引用给定原图；简单定义没有强行配图

新图片的实际文件检查、去除元数据、上传和回答插入由脚本负责；本轮没有执行新的 AI 位图生成，因此不把这条工具路径标为已完成真实生图测试

术语按已登记名称在展示时替换，保留底层原句；代码、网址、数学公式和有歧义的别名不替换，PDF 的页面像素也不改写

脚本在这些边界上更快、可重复，也不增加模型费用；语义不明确的别名宁可保留原词，不让模型在每次显示时重新改写整篇文章
