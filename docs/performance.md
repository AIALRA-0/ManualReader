# 1 这次减少了哪些重复工作

章节进度原先为每一章重新筛选全文，现在先累计各位置前的总数与已读数，再对章节范围做相减；同样的段落归属和手动勾选会得到相同结果；服务端在同一请求里复用已生成的章节计划，完成状态不再重复求同一份学习目录

恢复阅读位置时，刷新与位置恢复曾多次重建译文；现在统一由恢复过程重建一次，保留当前原文、译文、讲解和问题来源；删除的空函数、旧界面副本与拼接脚本不再参与发行包，当前启动器继续使用同一套 static 资源

# 3 怎样复查

下载并解压 v0.3.0，再在当前版本目录运行下面的命令，把基线目录改为实际解压的位置

~~~sh
# 在两个版本上使用相同的合成段落、目录和手动已读记录
python Demo/bench_progress.py --baseline ../ManualReader-v0.3.0
# 核对进度、完成状态和旧功能
python -m unittest discover -s Demo -p "test_*.py"
~~~

另用实际浏览器比较相同四章演示的章节切换与历史返回，并检查模糊加载恢复、三栏联动、问答写回与刷新；测试只写隔离 Demo 数据，不调用模型，不更改个人阅读记录
