# 怎样减少无关的限制说明

写作者继续使用 Terra high、普通服务与实时搜索；答案、术语和练习仍在同一次写作中完成，不增加审稿 Agent 或循环修复

规则同时进入 Agent 连接说明、讲解任务、问题输入和写作者指令；实际文本在 [reader_prompts.py](../reader_prompts.py)，设置页也可查看；材料没有交代用户需要的历史、名称或规格时，主动查原始文档、官方资料或原始研究，并复用同组检索结果

每部分先回答对应子问，再补齐原因；只保留会改变当前答案或解决当前具体误解的条件；没有查到的某项命名历史只在该子问说明，不把它扩展成整题无法回答，也不为填满答案编造命名故事；真实否定判断与必要条件继续保留

## 1 实际怎样测试

固定相同材料与问题，对照旧规则和新规则；第一组是三个处理器名称问题，第二组是 Redis 淘汰、Python 默认参数、水鸟辨认和一个没有作者日期的本地练习名，共七题；每题保留完整答案、术语和选择题，真实运行日志核对模型、档位、检索动作和缓存；跨领域样本没有写进提示词

第二组先发现仍附带没有被问到的命名者与年份说明，随后只调整一次规则，再用相同四题复测；表中新版采用最后一次结果；Python 保留了直接否定错误前提的答案，未把所有否定句一概删除；缺失作者年份的练习也没有被编造出处

按程序现有单价估算，第一组模型 token 费用约 0.0490 → 0.0496 美元，第二组约 0.0291 → 0.0419 美元；检索分别为两次和一至两次，单列记录，不混入 token 费用；这些是写作者测试，不包含开发、验收、部署和本轮维护对话，也不是订阅实际账单

## 2 怎样判断结果

七题都保存了可用 JSON、全部问题编号、回答、术语和练习；没有因为局部未知放弃整题；水鸟问题最终直接解释外形特征，没有另起命名者和年份的无关讨论；额外检索会增加耗时和用量，因此没有通过关闭搜索来换取更快数字

格式与接口由脚本回归，教学效果仍要在持续阅读中检验；本轮只针对已经确认的问题调整规则，不把小样本结果宣称为所有材料都不会再出现同类写法
