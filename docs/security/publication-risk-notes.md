# 1 公开发布时保留了什么

保留运行代码、必要的前端依赖和许可、启动脚本、合成缓存材料与脱敏截图

原工作目录同时存放程序和私人阅读记录，因此采用明确文件清单导出公开副本，没有把原目录的 Git 历史或数据库一起导出

# 2 哪些内容不能跟着代码上传

- 真实材料、用户问题、笔记、进度、配对数据库和连接码
- 原始模型任务日志、语音样本、模型权重和开发机路径
- 生产地址、反向代理密钥、身份验证配置和私人截图

公开前检查实际待提交文件，并运行秘密扫描；扫描通过不能证明数据可以公开，截图像素、许可和真实内容仍需人工核对

# 3 后续升级怎样避免覆盖记录

部署只替换代码和前端资源，先备份这些文件；阅读数据位于单独目录，不把合成示例复制到已有生产数据目录

发现误上传秘密时应先撤销凭据，再处理仓库历史；只删除当前文件不能让已经公开的秘密重新安全

# 4 本次更新公开了什么

只同步程序、合成测试和功能说明；本地生图原始日志、生产术语清单、数据库、录音和连接凭据没有进入提交。图像工具上传只接受当前写作目录或当前会话产生的文件，脚本重新编码图片以移除元数据

# 5 删除与待答判断需要共同检查什么

删除标记和旧回答片段不能代替当前回答状态；判断是否待答时，还要比较问题版本与回答对应版本。删除预览需要限定项目、调用者和当前追问分支，确认前发现内容变化就重新核对，不能复用旧预览删除新内容

发布材料只使用合成问题和固定答案，截图不带真实项目网址、配对信息或私人笔记；新增测试不需要模型、远程凭据或真实数据库

# 6 完整演示怎样避免沿用私人记录

完整演示先新建项目，保存原文和讲解并登记学习目录，再按当前章节写入合成问答；截图不从私人项目复制笔记、问题或进度。公开图册从同一份可装载材料生成，移除未引用的旧截图，实际运行只使用一套前端资源

性能比较使用固定输入，章节计数需要逐项相等，手动完成状态与回答展开状态分别回归；本地函数耗时与浏览器响应分开记录，避免把局部优化写成整个产品的速度承诺


# 7 实际使用截图怎样公开

用户明确要求用实际阅读界面替换只展示合成案例的首页；只读连接获取真实界面，所有写请求被拦住，逐张检查像素并去除图片元数据；公开截图不带网站地址、连接码、身份信息或笔记；原始项目数据、任务输入、授权与性能原始日志继续留在仓库外

网页选中的章节与写作任务的章节分开记录；页面换章不撤销已经准备的稿件任务，任务仍绑定同一项目、同一连接和同一章节；旧页面切章使用版本核对，避免覆盖较新选择；测试只在独立项目中写入

# 8 配色和写作测试怎样公开

配色功能只导出程序与合成测试，不导出个人保存的组合或设置文件；写作测试公开规则、方法、耗时和汇总用量，实际问题包、完整对话、原始模型输出与检索日志保存在仓库外；真实页面截图按上一节单独审核

维护时发现其他阅读对话已经更新同一答案，应保留较新版本并从历史核对本次修改；不能为了让验收截图一致而覆盖用户后续提问、回答或作答

# 9 项目文件怎样保留边界

每个项目使用独立的文件根目录，文件接口只接受根目录内的相对路径；隐藏文件正常展示，但不把数据库、连接令牌或笔记目录加入文件树。原件保留原编号，通过导入保存新版本；普通文件覆盖前核对版本，项目令牌不能借文件接口访问其他项目或修改全局设置

公开截图使用可重新装载的合成项目，只发布代码、测试和脱敏图片；浏览器页面、临时转换文件、文件根目录与真实学习数据均不加入 Git。办公文件在本机关闭宏后转换，不上传外部转换服务

文件树通过项目范围内的系统事件推送同步；连接撤销后停止推送。删除前核对整个目标的版本与子项，再移入项目专属回收站；恢复时拒绝覆盖同名文件。上传、编辑和菜单操作在切换项目时停止，避免把原项目文件写入新项目；拖动期间保留行位置，结束后合并目录变化

# 10 生成过程怎样避免带出凭据与旧内容

模型只接收当前任务、原图和必要工具，不传维护聊天、配对令牌或系统凭据。逐请求日志不记录授权头和隐藏思考；来源缓存按网站与项目隔离，只复用实际打开且已在有效写作中引用的网页短摘，过期后重查。缓存、日志、原始模型稿和实际测试材料保存在公开仓库之外。

发布只替换代码与展示适配；即使发现旧稿重复练习，也不改写原始正文或已读哈希。内部编号修正必须同步练习引用，不能修改用户问题编号、原文编号或追问关系。没有工具账单或某次请求没有用量回执时，费用标为未知，不填成零。


# 11 大项目交互修复怎样公开

旧问答中的定位引用可能落在当前章节范围之外；界面只临时补出被引用的原句，不为定位重建整份原文件。输入框按保存编号登记，更新一条问题不再扫描整页；章首是否允许提问与是否计入已读进度分别判断。

公开回归只使用合成编号、固定内容和程序中的实际判断；真实大项目的快照、问题、笔记、页面资源和浏览器原始日志继续留在公开仓库之外。部署只替换前端资源；进度、作答和笔记按原记录核对，不靠重新生成或清库修复交互。

# 12 术语定向补齐怎样保留用户记录

公开修改只包括规则、代码、合成测试和脱敏说明；实际项目清单、术语原稿、新稿、模型往返及服务器备份均保留在私有测试目录。旧术语修订沿用原编号，要求当前版本，可核对旧文本；成功后旧解释进入历史。Demo 与对照归档只同步框架，合格条目不重新生成。检查失败的批次不允许部分写入，笔记、练习和手动进度不参与修订。


# 13 性能缓存怎样保持项目与内容独立

缓存以项目和输入版本区分，并限制容量；材料响应按 Cookie、授权和项目编号区分，先通过原来的权限检查，再核对 ETag。正文、译文或练习题干变化时失效，笔记和回答展开不触发原文重传。并发读取同一版本只准备一次，失败不会缓存为成功。

只改写阅读器自己的界面资源版本号，上传的 HTML 原件保持原字节；图片和文字层带材料版本，旧页的异步响应不能覆盖新页。公开测试使用临时合成内容，真实项目快照、浏览器原始记录和代理测试凭据不进入仓库；部署不替换任何用户数据。


# 14 事务复用怎样避免覆盖更新

服务器内部的状态快照必须带原始数据库记录；取得写锁后逐字核对，完全一致才复用。快照尝试写入后即失效，错误回滚也不能把已经修改的内存对象再次保存。记录变化时重读，并在事务内再次检查切章版本；项目授权和用户进度规则继续由原接口执行。

请求连接在提交或回滚后及时关闭，常驻连接另由连接池管理。公开回归只使用合成问题与临时数据库，实际项目的原串、状态快照、性能记录和配对凭据均留在仓库外。


# 15 字节复用和排队计时怎样保持原权限

材料响应在授权和版本检查后复用字节；任务需要记录请求大小时仍取得实际内容，不用占位符代替正文。代理时间只参与耗时统计，不能改变授权、项目范围或写入结果。公开回归使用固定临时数据；实际请求时间线、网关记录和材料继续留在私有目录。

启动时提前的请求只读当前项目的材料和进度，沿用原认证；主程序领取后清除启动对象，避免切换后仍保留旧材料。正文准备使用独立的按版本复用锁，不再占用状态事务锁；写入、撤销和项目权限的核对不变。HTTP 快速编码不改磁盘记录，弱引用只影响辅助缓存的保留时间。

## 页面与后台分开后怎样保持授权与写入一致

页面只向管理员配置的本机端口转发，保留原请求授权和项目范围，后台仍执行原权限检查；不生成更宽权限的内部令牌。所有写接口和可能启动任务的读取入口都由同一后台进程处理，避免跨进程写锁失效。只读状态通过 SQLite 取得已提交快照，首次初始化仍用事务再次核对。

公开内容仅包含程序、合成回归和部署说明；实际代理路由、临时登录会话、大项目副本、性能日志与系统服务配置留在私有维护目录。排版缓存使用独立临时文件原子替换，工作区原件、版本、笔记、作答与阅读记录不参与部署替换。


## 加载进度怎样保留原来的请求规则

进度记录只保存阶段、字节数与等待时间，不保存请求正文、授权头或阅读内容；启动 HTML 只内嵌仓库内固定静态模块，不内嵌项目文件。自动重试仅作用于明确的 GET 读取，POST 写入、授权失败与已取消请求不重发；切换失败保留原项目上下文。公开回归只含合成数据；延迟控制端点、实际截图和服务器记录留在测试目录，不进入程序包。


## API 错误怎样避免泄漏页面或重复写入

JSON 解析错误只保留响应状态、错误分类和请求编号，不拼接返回页面、来源地址查询串或凭据。认证代理对 API 单独返回 JSON 错误，同时保留原有身份验证与项目限制；不要把修复错误响应变成关闭认证。登录页与临时错误页均使用合成响应回归，POST 不自动重发，当前选择只有有效回执才确认。实际代理配置、登录记录与写作原始回执留在私有测试目录。
